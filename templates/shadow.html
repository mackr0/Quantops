Shadow Model Evaluation

Fleet-wide A/B comparison of shadow models against the primary on every shadowed call{% if m.overview.since_days %} ({{ m.overview.since_days }}-day window){% else %} — the complete history of the experiment, from each arm's first call to now{% endif %}. Observational only — shadow calls never affect trading. The decision-quality judge is resolved disagreements: when a shadow model disagreed and the underlying prediction has since resolved, whose stance matched the realized price move. A @variant suffix on a model name marks a prompt-variant arm — the same model as the primary running revised instructions, so the comparison isolates the prompt rather than the model.

Read Shadow won / Primary won (rows where exactly one side matched), not a single side's total — and weigh them against Units, the distinct profile+symbol pairs behind those rows. The same name is re-reviewed every cycle and resolves against one price move, so row counts overstate how much independent evidence exists. A forecaster's HOLD is graded, not skipped: it wins when the move stayed inside ±1.5% and loses when it missed a real move, so a more decisive model can no longer score against an opponent that was unable to answer.

Moot is its own answer. The VETO-authority specialists (adversarial_reviewer, risk_assessor) decide whether a trade HAPPENS — they don't forecast direction, so they are scored against the P&L of the position that was actually opened. When the system passed on the candidate, no position existed and neither verdict could be right or wrong. A category sitting at 100% moot is not evidence of a tie; it is no evidence at all, and needs reviewed-and-traded candidates before it can say anything.

Bottom line — would following this arm have made more money?

Win rate and edge can disagree, and the money wins the argument. Points are position-size-agnostic returns: sizing isn't recorded on a shadow row, and multiplying by an assumed position would be invented precision.
